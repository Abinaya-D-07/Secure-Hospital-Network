# Secure-Hospital-Network

## About

A secure hospital network designed using **Cisco Packet Tracer** to provide reliable communication and controlled access between different departments and devices within a hospital.

## Features

* Department-based network segmentation
* Secure communication between departments
* VLAN implementation
* Inter-VLAN routing
* DHCP configuration
* Access Control Lists (ACLs)
* Secure device management using SSH
* Network connectivity and access control

## Technologies Used

* Cisco Packet Tracer
* VLAN
* Inter-VLAN Routing
* DHCP
* ACL
* SSH
* Networking Concepts

## Network Design

The network connects multiple hospital departments such as:

* Administration
* Doctors
* Nurses
* Pharmacy
* Laboratory
* Reception

VLANs and access-control mechanisms are used to isolate departments and restrict unauthorized access.
